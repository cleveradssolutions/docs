Rewarded ads let you offer users in-app items, such as continued gameplay, virtual currency, or other rewards, in exchange for their engagement with ads.
Rewarded ads boost engagement because users receive a tangible benefit for their time.

Rewarded ad management in Godot code is handled through the `CASRewarded` object in the `CASMobileAds.rewarded` property.
The rewarded ad is displayed by the native SDK on top of the game and is not a node of the scene tree.

## Load Ad
CAS provides two ways to load ads. Before using the ad, decide whether the SDK keeps ads loaded for you, or you manually manage each ad loading cycle in your code.

### Automatic loading
The `buffer_size` property sets the number of ads kept loaded automatically, up to 4.
A new ad is loaded after each display, and loading failures trigger automatic retry attempts, so `load()` is not needed.

```gdscript
func _ready() -> void:
	var rewarded := CASMobileAds.rewarded
	rewarded.loaded.connect(_on_rewarded_loaded)
	rewarded.failed_to_load.connect(_on_rewarded_failed_to_load)
	rewarded.buffer_size = 1 # [!code highlight]


func _on_rewarded_loaded() -> void:
	# Called when an ad is successfully loaded.
	print("Loaded")


func _on_rewarded_failed_to_load(error: CASAdError) -> void:
	# Called when an ad load failed.
	print("Load failed: ", error.message)
```

To have an ad ready more often, keep several ads loaded at the same time with `buffer_size` 2 to 4.
`show()` presents the loaded ad with the highest revenue. Use `get_loaded_count()` to get the number of loaded ads.

`buffer_size` can be set before `CASMobileAds.initialize()`, the ads start loading once the SDK is initialized.

### Manual loading
With the default `buffer_size = 0`, the ad is loaded only by `load()`. Call it each time you need a new ad, for example after `dismissed`.
Manual loading is useful when you only need to show a single ad per game screen, and the screens change frequently.

```gdscript
CASMobileAds.rewarded.load()
```

Ad content may take some time to load. To ensure the ad displays instantly when needed, load the ad in advance.
You can use the `loaded` signal to be notified when the ad is ready for display.

- Read more about `CASAdContentInfo` object in [Impression Level Data](godot/impression-level-data).  
- Read more about [CASAdError](godot/ad-errors) object. 
</Info>

## Show Ad
Be sure to listen to the `earned_reward` signal and reward the user for watching an ad.
The `earned_reward` signal is emitted before `dismissed`.

You can choose when to show the ad by calling `show()`:

```gdscript
func _ready() -> void:
	var rewarded := CASMobileAds.rewarded
	rewarded.earned_reward.connect(_on_rewarded_earned_reward)
	rewarded.failed_to_show.connect(_on_rewarded_failed_to_show)
	rewarded.dismissed.connect(_on_rewarded_dismissed)


func show_rewarded() -> void:
	CASMobileAds.rewarded.show()


func _on_rewarded_earned_reward(info: CASAdContentInfo) -> void:
	# Called when the user has earned the reward.
	print("Reward the user for watching the ad")


func _on_rewarded_failed_to_show(error: CASAdError) -> void:
	# Called when the ad failed to show full screen content.
	print("Failed to show: ", error.message)


func _on_rewarded_dismissed() -> void:
	# Called when the ad dismissed full screen content.
	print("Dismissed")
```

<Info>
When an error occurs during ad impression, only the `failed_to_show` signal is emitted.  
In this case, the `dismissed` signal will not be emitted since the impression is not considered successful.
</Info>

If the ad is not ready at that moment, the `failed_to_show` signal will be emitted with a reason.
You have the option to check `is_loaded()` if it's required by your app's logic.

```gdscript
if CASMobileAds.rewarded.is_loaded():
	# The ad is loaded here
	pass
```

## Game pause during the ad
While the ad is on screen, the game is paused the same way as when the app becomes inactive. 
Read more in [Interstitial Ads](godot/interstitial-ads#game-pause-during-the-ad).

## Server-side verification
Set custom data that is passed to your server-side reward verification callbacks. Pass an empty string to clear it.

```gdscript
CASMobileAds.rewarded.server_side_verification_data = "custom-data"
```

## Listening for the Ad Clicked
The `clicked` signal is emitted whenever a user clicks an ad. This can be useful for analytics, custom tracking, or UI reactions.

```gdscript
CASMobileAds.rewarded.clicked.connect(func():
	# Called when a click is recorded for a rewarded ad.
	pass)
```

## Mute Ad sounds
Indicates if the application’s audio is muted. Affects initial mute state for fullscreen ads. Use this method only if your application has its own volume controls (e.g., custom music or sound effect muting).

```gdscript
CASMobileAds.set_ad_sounds_muted(true)
```

Not muted by default.

## Release ad resource
Be sure to release ad resources when no longer needed. The ad options are kept, and the next `load()` creates a new ad.

```gdscript
CASMobileAds.rewarded.destroy()
```
