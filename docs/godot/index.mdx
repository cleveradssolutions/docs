---
title: CAS.AI plugin for Godot
description: This guide explains how to add the CAS.AI plugin to a Godot project.
---

Integrating CAS SDK into a game is the first step toward displaying ads and earning revenue. 
Once you've integrated and initialized the SDK, you can choose an ad format and follow the steps to implement it.

<Warning>
The CAS.AI plugin works on **mobile platforms only: iOS and Android**. 
Desktop, web and console exports are not supported, but the same game code still runs there without ads.
</Warning>

## Prerequisites
- Godot `{{ min.godot }}` or higher.
- iOS `{{ min.ios }}` or higher: set **Min iOS Version** in the iOS export preset.
- Xcode `{{ min.xcode }}` or higher.

## Add CAS.AI Godot plugin
1. Download `CAS-Godot-{{ versions.godot }}.zip` from the [latest release](https://github.com/cleveradssolutions/CAS-Godot/releases/latest).
2. Copy both folders from the archive into the root of your Godot project:
   - `addons/cas_ai/`
   - `ios/plugins/cas_ai/`
3. Open **Project > Project Settings > Plugins** and enable **CAS.AI**.

The plugin registers the `CASMobileAds` autoload, the entry point for all ads in your game code.
The native iOS plugin is enabled in every iOS export preset automatically.

<Info>
To update the plugin, delete both folders and copy them again from the new release.
</Info>

## Configure CAS ID
You need to register your app on the https://cas.ai platform. 
Open **Project > Project Settings**, turn on **Advanced Settings** and select the **CAS AI** section.

Set the registered **CAS ID** in the `cas_ai/ios/cas_id` setting.

<AccordionGroup>
<Accordion title="What is CAS ID in iOS?">

In most cases, a CAS ID is the same as your app store ID.  
You can find an app store ID in the URL of your app’s Apple App Store URL. For example, the URL is `apps.apple.com/us/app/id123456789` then app store ID is `123456789`.  

</Accordion>
</AccordionGroup>

The CAS ID is packed into the game with the project settings, so export the game again after changing it.

## Choose Mediated Networks
<Warning>
CAS.AI is a mediation SDK with no built-in live ad inventory. At least one ad network adapter or solution must be integrated before publishing to display ads and generate revenue.
</Warning>

Choose an integration path based on your app's target audience in the `cas_ai/ios/solution` setting. 
If you're unsure which solution best fits your application, please contact your account manager.

<Info>
During development, you can test ad formats using [Test Ads](godot/enabling-test-ads) without adding any ad network SDKs.
</Info>

Check the details of the ad network adapters supported by CAS.AI Mediation in the [iOS repository](https://github.com/cleveradssolutions/CAS-iOS/blob/master/Adapters/README.md) table.

<AccordionGroup>
<Accordion defaultOpen title="Optimal Ads Solution">

Recommended for **most applications** targeting a **general or mixed audience**. Includes a broad set of stable, high-performance networks.

Select `Optimal Ads` in the `cas_ai/ios/solution` setting. This is the default value.

</Accordion>
<Accordion title="Families Ads Solution">

Required for applications **directed exclusively at children**, in accordance with the [Google Play Families Policy](https://support.google.com/googleplay/android-developer/answer/12918983?hl=en) and fully compatible with the [Children’s Online Privacy Protection Act (COPPA)](https://www.ftc.gov/tips-advice/business-center/privacy-and-security/children%27s-privacy).

Select `Families Ads` in the `cas_ai/ios/solution` setting.

</Accordion>
<Accordion title="VPN Compliant Ads Solutions">

Designed specifically for applications that provide VPN or proxy services. This solution includes partner networks that comply with VPN-related traffic policies and restrictions.

Select `VPN Compliant Ads` in the `cas_ai/ios/solution` setting.

</Accordion>
<Accordion title="Choice networks">

Advanced publishers familiar with ad network integrations can configure their own set of adapters. 

1. Select `None` in the `cas_ai/ios/solution` setting to include no solution, or keep a solution to extend it.
2. Add adapters to the `cas_ai/ios/adapters` list. Each value is `CASMediation` followed by the adapter name (first column) from the [iOS Adapters table](https://github.com/cleveradssolutions/CAS-iOS/blob/master/Adapters/README.md).

Below, as an example, only GoogleAds, Exchange, and DTExchange are shown.
```
CASMediationGoogleAds
CASMediationExchange
CASMediationDTExchange
```

The iOS export checks that each name exists in the selected CAS iOS SDK version and shows an error otherwise.

</Accordion>
</AccordionGroup>

## Advertising Identifier
CAS Mediation uses the [Apple Identifier for Advertisers (IDFA)](https://developer.apple.com/documentation/adsupport) to deliver personalized and more relevant ads to each user.  

The [App Tracking Transparency authorization request](https://developer.apple.com/documentation/bundleresources/information_property_list/nsusertrackingusagedescription) for accessing the IDFA is shown by the SDK with the text from the `cas_ai/ios/tracking_usage_description` setting. 
The plugin sets a default text, you can replace it with a custom message describing your usage.

<AccordionGroup>
<Accordion title="Usage description examples">

- Your data will remain confidential and will only be used to provide you a better and personalised ad experience
- Your data will be used to provide you a better and personalised ad experience
- Your data will be used to create a customized experience tailored to your interests
- Allowing tracking will enable more personalized ads for you
- We try to show ads for apps and products that will be most interesting to you based on the apps you use
- This identifier will be used to deliver personalized ads to you
- This only uses device info for more interesting and relevant ads

</Accordion>
</AccordionGroup>
