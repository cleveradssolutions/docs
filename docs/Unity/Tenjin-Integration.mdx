Tenjin handles install attribution and purchase tracking. The CAS SDK initializes Tenjin automatically, so the only thing left to set up is tracking in-app purchases.
 
## Track purchases
Choose one of the following methods to report in-app purchases to Tenjin.
1. Report purchases with the CAS SDK
2. Report purchases with CAS Publishing Hub

### (Option 1) Report purchases with the CAS SDK
Report each completed purchase with `CAS.MobileAds.ReportPurchase(...)`. The CAS SDK forwards it to Tenjin automatically, so no separate Tenjin code is needed.

<Card title="Purchase Info" href="/Unity/Purchase-Info">
Step-by-step guide to creating a `PurchaseInfo` and reporting it with `CAS.MobileAds.ReportPurchase(...)`.
</Card>

### (Option 2) Report purchases with CAS Publishing Hub
If you installed the SDK with [CAS Publishing Hub](/Unity/CAS-Publishing-Hub-Integration) and your project uses Unity IAP, report each completed purchase with:

```csharp
CASHub.ReportPurchase(product, order);
```

<Info>
`CASHub.ReportPurchase` is available only when Unity IAP is present in the project.
</Info>

## Share purchase validation keys
If your app includes in-app purchases, you must provide your manager with the following so Tenjin can track them:
 
- **Public Key** for the Android app
- **Shared Secret** for the iOS app (only for subscriptions)

<AccordionGroup>
<Accordion title="Where to find the Public Key (Android)">
In the Google Play Console, select your app and go to: `Monetize > Monetization setup > Google Play Billing > Licensing`. Copy the **Base64-encoded RSA public key**.
</Accordion>
<Accordion title="Where to find the Shared Secret (iOS)">
In App Store Connect, select your app and go to: `App Information > App-Specific Shared Secret`. Copy the **App-Specific Shared Secret**.
</Accordion>
</AccordionGroup>

<Warning>
Without the Public Key (Android) and Shared Secret (iOS), Tenjin will not be able to track your purchases.
</Warning>
