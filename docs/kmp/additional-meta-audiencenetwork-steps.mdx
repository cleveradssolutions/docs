## Data Processing Options for US Users
Meta Audience Network Data Processing Options for US Users Limited Data Use is a data processing option that gives you more control over how your data is used in Meta’s systems and better supports your compliance efforts with various US state privacy regulations. To utilize this feature, you must proactively enable Limited Data Use.
Visit [Meta’s developer documentation](https://developers.facebook.com/docs/marketing-apis/data-processing-options) for details.

If you do not want to enable Limited Data Use (LDU) mode, pass an empty string as a value of mediation extras with key `FB_dp` in the initialize method:
```kotlin
CASMobileAds.initialize(
    context = context,
    casId = casId,
    mediationExtras = mapOf("FB_dp" to ""), // [!code highlight]
)
```
To enable LDU for users and specify user geography, set `"LDU"` in `mediationExtras`:
```kotlin
CASMobileAds.initialize(
    context = context,
    casId = casId,
    mediationExtras = mapOf("FB_dp" to "LDU"), // [!code highlight]
)
```

<Info>
The Meta Audience Network adapter is added per platform: `audienceNetwork = true` in the `cas { }` block on
Android, and the `CASMediationAudienceNetwork` library product of the CAS Swift Package on iOS.
</Info>
