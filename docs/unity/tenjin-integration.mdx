Tenjin handles install attribution and purchase tracking. The CAS SDK initializes Tenjin automatically, so the only thing left to set up is tracking in-app purchases.
 
## Track purchases
Choose one of the following methods to report in-app purchases to Tenjin.

<Accordion title="(Option 1) Report purchases with the CAS SDK">
Report each completed purchase with `CAS.MobileAds.ReportPurchase(...)`. The CAS SDK forwards it to Tenjin automatically, so no separate Tenjin code is needed.

```csharp
// 1. Create PurchaseInfo
var purchase = new CAS.PurchaseInfo(
    product.definition.id,
    product.metadata.localizedPrice,
    product.metadata.isoCurrencyCode,
    quantity // optional, 1 by default
);

// 2. Recommended: attach validation data
var unityReceipt = JsonUtility.FromJson<UnifiedReceipt>(order.Info.Receipt);
var store = unityReceipt.Store;
var payload = unityReceipt.Payload;
var isSubscriptionType = product.definition.type == ProductType.Subscription;

if (store.Equals("GooglePlay"))
{
    purchase.SetGoogleValidation(payload, isSubscriptionType);
}
else if (store.Equals("AppleAppStore"))
{
    purchase.SetAppleValidation(
        order.Info.transactionID,
        order.Info.Apple?.jwsRepresentation,
        order.Info.Apple?.AppReceipt,
        isSubscriptionType
    );
}
else if (store.Equals("AmazonAppStore"))
{
    purchase.SetAmazonValidation(payload);
}

// 3. Report
CAS.MobileAds.ReportPurchase(purchase);
```

See the [Purchase Info](/unity/purchase-info) guide for details on each parameter and validation method.
</Accordion>

<Accordion title="(Option 2) Report purchases with CAS Publishing Hub">
If you installed the SDK with [CAS Publishing Hub](/unity/cas-publishing-hub-integration) and your project uses Unity IAP, report each completed purchase with:

```csharp
CASHub.ReportPurchase(product, order);
```

<Info>
`CASHub.ReportPurchase` is available only when Unity IAP is present in the project.
</Info>
</Accordion>

## Share purchase validation keys
If your app includes in-app purchases, you must provide your manager with the following so Tenjin can track them:
 
- **Public Key** for the Android app — in the Google Play Console, select your app and go to `Monetize > Monetization setup > Google Play Billing > Licensing`. Copy the **Base64-encoded RSA public key**.
- **Shared Secret** for the iOS app (only for subscriptions) — in App Store Connect, select your app and go to `App Information > App-Specific Shared Secret`. Copy the **App-Specific Shared Secret**.

<Warning>
Without the Public Key (Android) and Shared Secret (iOS), Tenjin will not be able to track your purchases.
</Warning>
