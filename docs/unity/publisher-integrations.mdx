<Success>
You don't need to complete any additional integrations if your app is not part of the CAS.AI Mobile Game Publisher program.
</Success>

This guide helps publishers prepare a project for working with CAS.AI Mobile Game Publisher. By the end you will have analytics and event data flowing out of your app, and the attribution setup needed to run a test purchase.
 
The preparation consists of three parts. Complete them together with your CAS.AI manager, who will provide the keys and credentials referenced in the steps.

## 1. Set up the Firebase project
Create and link a Firebase project to collect analytics and export event data.

<Card title="Firebase" href="/unity/firebase-integration">
Create the project, share permissions and link BigQuery.
</Card>

## 2. Integrate the CAS SDK
Install the CAS SDK in the [standard way](/unity), or use [CAS Publishing Hub](/unity/cas-publishing-hub-integration), which installs and configures the CAS SDK, Tenjin and Firebase Analytics in one wizard.

## 3. Integrate Tenjin
Set up Tenjin to attribute installs and track in-app purchases.

<Card title="Tenjin" href="/unity/tenjin-integration">
Report in-app purchases to Tenjin.
</Card>
